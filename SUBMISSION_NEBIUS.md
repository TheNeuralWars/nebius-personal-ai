## Short description

Hermes Personal AI is a personal agent that answers only from its own memory and refuses to show you an answer that breaks your canon — the facts you have fixed as true (ages, dates, names, tone rules). NVIDIA Nemotron, served on Nebius Token Factory, plans and drafts every answer; CanonGuard checks the draft, a repair loop fixes violations before they are ever shown, and every model call writes an append-only receipt (request id, model, latency, tokens — never credentials).

## Long description

**Problem.** Personal assistants forget, contradict what you told them, slip into corporate filler, and cannot tell you where an answer came from or what it cost. For a *personal* AI that is the whole job: it should know your facts, keep them straight, and show its work.

**What Hermes does.**
1. **Remembers with provenance.** Memories (events, canon facts, task logs) are recalled with scores and source; corrections supersede, never silently overwrite. The memory layer implements the Meterless H-MEM spec (hybrid retrieval, feedback deltas, audit ledger, sleep/dream cycles, conflict resolution) and passes the spec's own conformance suite 13/13.
2. **Plans before it answers.** NVIDIA Nemotron (`nvidia/nemotron-3-super-120b-a12b` on Nebius Token Factory) reads the recalled memories and writes a short plan plus the facts the answer must respect.
3. **Generates on Nemotron.** The answer draft is generated by the same Nemotron model on Token Factory.
4. **Guards the canon.** CanonGuard checks the draft against `canon.json` (protected facts + banned phrases). Violations are repaired (max 2 rounds) and the user only ever sees the clean answer — the live demo shows a draft leaking "As an AI…" being caught and fixed.
5. **Knows what it spent.** Every Token Factory call is metered into append-only JSONL receipts.
6. **Dreams, with permission.** Nemotron drafts insights from memory; they only become long-term memory after approval, with lineage.

**How it uses Nebius Token Factory + NVIDIA open models at runtime.**
- All runtime inference in the demo path goes to `https://api.tokenfactory.nebius.com/v1/chat/completions` (OpenAI-compatible) — default model in `llm.py`: **`nvidia/nemotron-3-super-120b-a12b`** (NVIDIA Nemotron 3 Super, open weights).
- The planner (`planner.py`) uses the same endpoint (`OMNIROUTE_BASE_URL=https://api.tokenfactory.nebius.com/v1`, `NEMOTRON_MODEL=nvidia/nemotron-3-super-120b-a12b`; `nvidia/Nemotron-3-Ultra-550b-a55b` available for heavier reasoning).
- The public demo at https://goalworld.fun/hermes-demo/ makes real Token Factory calls on every click (rate-limited to protect credits) and prints the Token Factory request ids it got back.
- Evidence in repo: `proofs/nebius-tokenfactory-live.txt` (HTTP 200 from Token Factory with `nvidia/nemotron-3-super-120b-a12b` + live demo transcript), `proofs/hackathon-demo-tokenfactory.txt` (planner + dream insight + generation on Token Factory), `proofs/nemotron-receipts.jsonl`, `proofs/demo-web-live-run.json`.

## Challenges

- Moving the reasoning core from a free gateway to Token Factory without changing the agent: we kept one OpenAI-compatible client and switched defaults/env, so the same loop runs on `nvidia/*` models end to end.
- Nemotron is a reasoning model: on tight token budgets it can spend the budget thinking. We tuned prompts and limits so plans and drafts come back complete in ~1–3 s.
- Keeping a public demo free and safe: fixed scenarios, 200-char input, per-IP and daily caps, key read from a file inside the container and never returned or logged; gitleaks gate before every push.

## Accomplishments

- A personal AI that *never shows* a canon-violating answer — caught and repaired live, on screen.
- End-to-end runtime on Nebius Token Factory + NVIDIA Nemotron with request-id-level receipts.
- Memory layer verified by an external conformance suite (13/13), 41 unit tests green.
- Zero-cost hosting on existing infrastructure; zero secrets in git (gitleaks: 0 findings).

## What we learned

Grounding + a deterministic guard after the model beats bigger prompts: Nemotron does the reasoning, the canon decides what is allowed to reach the user.

## What's next

User-editable canon profiles, scheduled dream cycles, and exposing the guarded loop as an OpenAI-compatible endpoint so any personal app can use it.
